# CodeAlpha Task 3 — Data Visualization

## Objective
Create charts from the sample retail sales dataset to communicate business insights.

## Run
```bash
python -m pip install -r requirements.txt
python visualize_sales.py
```

## Charts generated in `output/`
- `revenue_by_category.png`
- `profit_by_region.png`
- `monthly_revenue_trend.png`
- `revenue_vs_profit_scatter.png`

The dataset is synthetic. Use chart titles, axis labels, and the charts when explaining your findings.
