CODEALPHA DATA ANALYTICS INTERNSHIP — TASK 1, TASK 2, TASK 3
===========================================================

इस ZIP में 3 अलग-अलग Python projects हैं:
1. Task 1 - Web Scraping
2. Task 2 - Exploratory Data Analysis (EDA)
3. Task 3 - Data Visualization

WINDOWS / VS CODE में चलाने का तरीका:
1. ZIP को Extract All करें।
2. VS Code में extracted folder खोलें।
3. Terminal > New Terminal खोलें।
4. किसी project folder में जाएँ, उदाहरण: cd Task2_EDA
5. Libraries install करें: python -m pip install -r requirements.txt
6. Python file चलाएँ:
   Task 1: python scraper.py
   Task 2: python eda_analysis.py
   Task 3: python visualize_sales.py

अगर `python` काम न करे तो `py` try करें।

Task 1 को चलाने के लिए internet connection चाहिए। यह केवल practice website
https://books.toscrape.com/ पर कम pages scrape करता है।
Task 2 और Task 3 में sample CSV dataset शामिल है और वे offline चल सकते हैं।
